“批量重命名”是一款面向 Windows 的中文桌面工具，用来整理一个目录及其多层子目录中的文件夹和文件名称。它把搜索结果、替换后的名称和不能执行的原因放在同一张表里，让批量操作在真正写入磁盘前保持可见、可检查。

程序只依赖 Python 标准库运行，可通过 PyInstaller 发布为单文件 EXE。普通文本规则适合日常整理，正则表达式则用于日期、序号、标签和名称片段等结构化场景。

默认窗口以 960×680 打开，适合在常见桌面空间中与资源管理器并排使用；窗口放大或最大化后，新增空间会自动交给匹配结果列表。

![批量重命名主界面：扫描范围、重命名规则、完整统计与统一结果表](docs/images/batch-rename-main.png)

上图使用“项目 → 归档”的普通文本规则生成真实预览。左侧扫描范围约占 35%，右侧规则区约占 65%；输入查找内容后可按 Enter、点击输入框后的“扫描”，或点击“结果预览”。工具栏同时显示匹配、可修改、名称未变化与阻止执行数量，右侧的 100 只限制表格显示条数。

结果表按类型、所在目录、原名称、新名称、状态和说明排列。青绿色新名称便于逐项核对；绿色表示可以安全修改，红色表示目标冲突或其他阻止原因。截图中的扫描仍处于预览阶段，只有继续点击“确认并重命名”并通过汇总确认后才会写入磁盘。

## 适合处理的场景

- 把项目名称中的“旧版”统一替换为“新版”。
- 整理相机生成的 `IMG_001`、`IMG_002` 等序号名称。
- 删除批量文件名前的 `[已审核]`、`[归档]` 等标签。
- 将 `2026-08-27` 整理为 `20260827`。
- 清理重复空格、混用的连接符、旧版前缀和副本后缀。
- 将 JPEG、JPG 等扩展名整理为统一写法。
- 在不修改磁盘的情况下，仅查询多层目录里有哪些名称符合条件。

## 功能

### 清楚的匹配结果

扫描以“名称是否符合查找条件”为准，而不是以“替换后是否发生变化”为准。即使查找和替换内容相同，符合条件的项目仍会出现在结果中，并标记为“名称未变化”。这样既可以验证规则，也可以把程序当作目录名称查询工具使用。

文件夹和文件显示在同一张表中，按“类型、所在目录、原名称、新名称、状态、说明”的顺序阅读，默认以文件夹优先、文件其次、同类名称自然顺序排列。新名称使用青绿色单独强调，便于在执行前快速对照。匹配总数、可修改数、名称未变化数和阻止执行数始终在一行分别统计，不会把“没有执行动作”误写成“没有匹配”。

类型和状态列保持紧凑，名称与所在目录自动分享其余宽度。横向滚动条只在确实需要时出现；名称、路径或说明被列宽缩短时，把鼠标停在对应单元格即可查看完整内容。

### 紧凑而可伸缩的界面

扫描范围与重命名规则按约 35% 和 65% 分配宽度，让目录设置保持紧凑，把更多空间留给查找、快捷扫描和替换内容。查找与替换输入框保持在同一行，匹配统计完整展开，结果预览默认最多列出 100 条。960×680 是完整可操作的起点，不是固定画布：手动放大或最大化窗口后，列表会自然增加可见行数，不会在设置区制造大片空白。

输入查找内容后，可以直接按 Enter 或点击输入框后的“扫描”；主操作区的“结果预览”提供相同入口。三种操作都会应用当前目录、层级、对象类型、扩展名和替换规则，不存在统计口径不同的简化扫描模式。

输入框、数值框、选择控件、按钮、提示卡、滚动条和进度条使用同一套深蓝与青绿色视觉语言。焦点、悬停、禁用和执行状态都有清晰差异，仍保持 Windows 桌面工具熟悉的操作方式。

### 普通文本与正则表达式

普通模式按原样查找文本，并替换名称里的每一处匹配。替换内容可以留空，表示删除匹配文本。

正则模式支持 Python 正则语法。不了解正则也可以直接打开“正则模板”：程序内置 6 类 15 条经过真实规则验证的常用模板，先展示用途和处理前后效果，再通过“一键应用此规则”填写查找、替换及必要选项。应用模板不会扫描目录，也不会直接修改文件。

| 用途 | 查找表达式 | 替换内容 | 示例结果 |
| --- | --- | --- | --- |
| 压缩日期 | `(\d{4})-(\d{2})-(\d{2})` | `\1\2\3` | `2026-08-27` → `20260827` |
| 统一日期分隔符 | `(\d{4})[._/](\d{2})[._/](\d{2})` | `\1-\2-\3` | `2026.08.27` → `2026-08-27` |
| 保留图片序号 | `IMG_(\d+)` | `照片_\1` | `IMG_001.jpg` → `照片_001.jpg` |
| 删除方括号标签 | `\[[^\]]+\]` | 留空 | `[已审核]合同.docx` → `合同.docx` |
| 合并连续空格 | `\s{2,}` | 单个空格 | `项目  最终  版本` → `项目 最终 版本` |
| 删除副本后缀 | `[_-](副本\|copy)$` | 留空 | `预算_副本.xlsx` → `预算.xlsx` |
| 交换名称片段 | `(.+)_([A-Z]+)` | `\2_\1` | `project_FINAL.txt` → `FINAL_project.txt` |
| 统一 JPEG 扩展名 | `(?i)\.jpe?g$` | `.jpg` | `照片.JPEG` → `照片.jpg` |

模板按日期时间、编号整理、标签清理、文本清理、片段调整和扩展名分类。涉及扩展名的模板会自动开启“包含扩展名”，并在模板详情中提醒核对；其他模板默认继续保护文件扩展名。

### 层级与对象范围

- 默认扫描到最深子目录。
- 可限制为 1–N 层；第 1 层表示根目录中的直接子项。
- 可单独选择文件夹、文件或两者。
- 所选根目录本身不参与匹配和重命名。
- 符号链接不会被跟随，避免扫描越出所选目录。

### 扩展名保护

文件扩展名默认不参与替换。例如查找 `jpg` 时，`照片.jpg` 会作为匹配结果列出，但状态会说明扩展名受到保护，因此不会执行动作。只有明确勾选“包含扩展名”后，规则才处理完整文件名。

### 安全执行

- 目标名称已经存在时不覆盖，直接标明冲突原因。
- 多个来源生成同一个目标名称时，相关项目全部停止执行。
- Windows 非法字符、保留设备名、空名称和尾随空格或句点会提前拦截。
- 扫描完成后若文件系统发生变化，执行时再次检查来源和目标。
- 深层项目先处理，父目录最后改名，避免父路径变化导致子项目失效。
- 执行前展示汇总并二次确认；执行中显示当前项目和总体进度。

程序不会覆盖已有名称，也不会自动撤销已完成的操作。重要目录仍建议先备份。

## 开始使用

### 使用单文件程序

运行 `BatchRename.exe` 后：

1. 选择根目录。
2. 保持“扫描到最深处”，或设置最大层级。
3. 输入查找内容和替换内容；需要结构化处理时，也可以打开“正则模板”选择常用规则并一键应用。
4. 选择普通文本或正则表达式，以及文件夹、文件和扩展名范围。
5. 在查找框按 Enter、点击旁边的“扫描”，或点击“结果预览”，然后按类型、所在目录、原名称、新名称、状态和说明检查结果。
6. 确认存在可修改项目后，点击“确认并重命名”。
7. 阅读最终汇总，确认后等待进度完成。

“预览上限”默认是 100 条，只控制界面显示的前几条结果，不改变完整匹配统计和最终执行范围。

### 从源码运行

需要 Python 3.11 或更高版本：

```powershell
python main.py
```

运行程序本身不需要安装第三方库。

## 测试与构建

安装开发依赖：

```powershell
python -m pip install -r requirements-dev.txt
```

运行测试：

```powershell
python -m pytest -v
```

构建带应用图标的单文件 EXE：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本会先运行完整测试，测试通过后才生成 `dist\BatchRename.exe`。
