# 批量重命名工具体验改版设计

## 设计目标

本轮改版解决三个核心问题：搜索结果与可执行改名被混为一谈、预览信息被拆散在两个标签页、界面缺乏清晰的视觉层级。同时补齐可直接使用的正则示例、应用图标、中文开发日志和面向使用者的项目说明。

## 搜索与执行语义

扫描首先判断名称是否符合搜索条件，再计算替换结果和执行状态。所有符合搜索条件的文件夹和文件都进入结果列表，即使替换后的名称与原名称相同。

例如查找“众川”、替换为“众川”时，`众川合同.docx` 必须出现在列表中：

- 匹配总数计为 1，而不是 0。
- 新名称仍显示为 `众川合同.docx`。
- 状态显示“名称未变化”。
- 可执行数量计为 0。
- 汇总区提示“已匹配 1 项，但本次没有可执行动作”。

所选根目录自身继续不参与搜索和重命名。文件扩展名保护仍然有效；如果搜索只命中受保护的扩展名，项目仍进入匹配列表，并说明扩展名受保护，因此未产生变化。

## 统一结果列表

文件夹和文件不再使用两个标签页。结果表增加“类型”列，统一列出类型、原名称、新名称、所在目录、状态和说明。默认排序规则固定为：

1. 文件夹在前，文件在后。
2. 同类项目按原名称进行不区分大小写的自然排序。
3. 同名时再按所在目录排序，保证结果稳定。

预览条数表示统一列表的显示上限，不影响匹配统计和实际执行范围。统计区分别展示匹配总数、可修改数、无动作数和阻止执行数。

## 正则示例

规则区增加“正则示例”入口，打开后展示可直接套用的查找、替换和结果示例：

- 日期压缩：`(\d{4})-(\d{2})-(\d{2})` → `\1\2\3`。
- 图片序号：`IMG_(\d+)` → `照片_\1`。
- 删除方括号标签：`\[[^\]]+\]` → 空文本。
- 交换名称片段：`(.+)_([A-Z]+)` → `\2_\1`。

用户可以点击“应用此示例”直接填入规则。界面同时解释捕获组、反斜杠和扩展名保护的影响；无效表达式继续即时提示。

## 视觉与布局

继续采用原生 Tkinter/ttk，避免增加运行依赖和显著扩大单文件体积。界面使用现代浅色主题：深蓝标题、青绿色主操作色、柔和灰色背景、白色内容卡片和明确的状态色。

页面结构调整为：

1. 顶部品牌区：应用图标、名称、用途说明、帮助入口。
2. 两列设置区：左侧扫描范围，右侧重命名规则与示例入口。
3. 操作与统计条：主按钮、匹配汇总和预览条数。
4. 单一结果表：占据主要窗口空间。
5. 底部进度与状态区：显示当前动作、成功/跳过/失败计数。

危险动作继续二次确认；扫描和执行期间锁定会影响结果的输入控件。说明文字使用自然、面向任务的表达，不在界面中堆叠开发术语。

## 应用图标

生成一枚无文字、透明背景的方形图标，核心图形为文件夹、循环重命名箭头和小型编辑标记。配色与界面一致，输出高分辨率 PNG 和包含 16、24、32、48、64、128、256 像素的 ICO。图标同时用于窗口、任务栏和 PyInstaller 产物。
