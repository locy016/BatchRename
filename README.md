“批量重命名”是一款面向 Windows 的中文桌面工具，用来整理一个目录及其多层子目录中的文件夹和文件名称。它把搜索结果、替换后的名称和不能执行的原因放在同一张表里，让批量操作在真正写入磁盘前保持可见、可检查。

程序只依赖 Python 标准库运行，可通过 PyInstaller 发布为单文件 EXE。普通文本规则适合日常整理，正则表达式则用于日期、序号、标签和名称片段等结构化场景。

## 适合处理的场景

- 把项目名称中的“旧版”统一替换为“新版”。
- 整理相机生成的 `IMG_001`、`IMG_002` 等序号名称。
- 删除批量文件名前的 `[已审核]`、`[归档]` 等标签。
- 将 `2026-08-27` 整理为 `20260827`。
- 在不修改磁盘的情况下，仅查询多层目录里有哪些名称符合条件。

## 功能

### 清楚的匹配结果

扫描以“名称是否符合查找条件”为准，而不是以“替换后是否发生变化”为准。即使查找和替换内容相同，符合条件的项目仍会出现在结果中，并标记为“名称未变化”。这样既可以验证规则，也可以把程序当作目录名称查询工具使用。

文件夹和文件显示在同一张表中，默认按文件夹优先、文件其次、同类名称自然顺序排列。匹配总数、可修改数、名称未变化数和阻止执行数分别统计，不会把“没有执行动作”误写成“没有匹配”。

### 普通文本与正则表达式

普通模式按原样查找文本，并替换名称里的每一处匹配。替换内容可以留空，表示删除匹配文本。

正则模式支持 Python 正则语法。程序内置四组经过实际规则验证的示例，可在“正则示例”窗口查看说明并直接应用：

| 用途 | 查找表达式 | 替换内容 | 示例结果 |
| --- | --- | --- | --- |
| 压缩日期 | `(\d{4})-(\d{2})-(\d{2})` | `\1\2\3` | `2026-08-27` → `20260827` |
| 保留图片序号 | `IMG_(\d+)` | `照片_\1` | `IMG_001.jpg` → `照片_001.jpg` |
| 删除方括号标签 | `\[[^\]]+\]` | 留空 | `[已审核]合同.docx` → `合同.docx` |
| 交换名称片段 | `(.+)_([A-Z]+)` | `\2_\1` | `project_FINAL.txt` → `FINAL_project.txt` |

### 层级与对象范围

- 默认扫描到最深子目录。
- 可限制为 1–N 层；第 1 层表示根目录中的直接子项。
- 可单独选择文件夹、文件或两者。
- 所选根目录本身不参与匹配和重命名。
- 符号链接不会被跟随，避免扫描越出所选目录。

### 扩展名保护

文件扩展名默认不参与替换。例如查找 `jpg` 时，`照片.jpg` 会作为匹配结果列出，但状态会说明扩展名受到保护，因此不会执行动作。只有明确勾选“包含扩展名”后，规则才处理完整文件名。

### 安全执行

- 目标名称已经存在时不覆盖，直接标明冲突原因。
- 多个来源生成同一个目标名称时，相关项目全部停止执行。
- Windows 非法字符、保留设备名、空名称和尾随空格或句点会提前拦截。
- 扫描完成后若文件系统发生变化，执行时再次检查来源和目标。
- 深层项目先处理，父目录最后改名，避免父路径变化导致子项目失效。
- 执行前展示汇总并二次确认；执行中显示当前项目和总体进度。

程序不会覆盖已有名称，也不会自动撤销已完成的操作。重要目录仍建议先备份。

## 开始使用

### 使用单文件程序

运行 `BatchRename.exe` 后：

1. 选择根目录。
2. 保持“扫描到最深处”，或设置最大层级。
3. 输入查找内容和替换内容。
4. 选择普通文本或正则表达式，以及文件夹、文件和扩展名范围。
5. 点击“扫描匹配”，检查结果表中的原名称、新名称、状态和说明。
6. 确认存在可修改项目后，点击“确认并重命名”。
7. 阅读最终汇总，确认后等待进度完成。

“预览上限”只控制界面显示的前几条结果，不改变完整匹配统计和最终执行范围。

### 从源码运行

需要 Python 3.11 或更高版本：

```powershell
python main.py
```

运行程序本身不需要安装第三方库。

## 测试与构建

安装开发依赖：

```powershell
python -m pip install -r requirements-dev.txt
```

运行测试：

```powershell
python -m pytest -v
```

构建带应用图标的单文件 EXE：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本会先运行完整测试，测试通过后才生成 `dist\BatchRename.exe`。
