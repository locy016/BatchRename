# 批量重命名工具设计

## 目标

开发一个 Windows 图形界面工具，扫描用户选择目录下 1–N 层或全部层级的文件夹与文件，通过普通文本或正则表达式生成批量重命名预览，经用户二次确认后执行，并在全过程提供详尽说明、状态反馈和进度展示。最终使用 PyInstaller 发布为单文件 EXE。

## 安全原则

- 所选根目录不参与改名。
- 默认扫描全部层级，可限制为 1–N 层；第 1 层表示根目录中的直接子项。
- 文件扩展名默认不参与替换，用户可显式开启。
- 目标名称为空、含 Windows 非法字符、使用保留设备名或以空格/句点结尾时不执行。
- 目标已存在或多个来源会生成同一目标时跳过，并在预览与结果中说明。
- 扫描后若文件系统发生变化，执行时再次检查来源与目标，避免覆盖。
- 符号链接不跟随，防止扫描越出所选目录。
- 先处理深层项目，再处理父目录，保证父目录改名不会使尚未处理的子项路径失效。

## 架构

- `batch_rename/models.py`：扫描选项、候选项、状态和执行结果等数据结构。
- `batch_rename/core.py`：规则编译、名称转换、目录扫描、冲突检测和安全执行，不依赖 GUI，便于测试。
- `batch_rename/app.py`：Tkinter/ttk 主窗口、说明提示、预览表格、确认对话框、后台线程和进度消息。
- `main.py`：应用入口。
- `tests/`：核心规则、层级扫描、冲突处理和执行顺序测试。
- `BatchRename.spec` 与 `build.ps1`：PyInstaller 单文件、无控制台窗口构建。

## 界面与交互

主窗口包含扫描范围、重命名规则、匹配统计、分类预览和操作状态五部分。目录、层级、匹配模式、扩展名开关、对象类型和预览条数均配有可见说明或悬停提示。状态栏说明下一步动作；扫描与执行在后台线程运行，界面不冻结。

预览表格按文件夹和文件分别展示前若干条，包含类型、原名称、新名称、所在目录和状态。执行按钮仅在扫描完成且至少存在一个可安全执行项目时启用。执行前展示汇总确认；执行中展示进度、当前对象和成功/跳过/失败计数；结束后展示摘要与详细记录。

## 数据流

1. 用户选择目录并填写规则。
2. GUI 校验输入并创建不可变扫描选项。
3. 后台扫描生成完整候选列表并做批内与文件系统冲突检查。
4. GUI 仅截取配置数量用于显示，统计仍基于完整列表。
5. 用户确认后，后台按路径深度降序执行全部“可修改”候选项。
6. 每处理一项向 GUI 发送进度，结束后返回逐项结果。

## 错误处理

可预期输入问题在扫描前用中文解释；单个文件系统错误记录到对应候选或执行结果，不中断其余项目；无法访问根目录等全局错误会终止当前操作并弹出提示。工具不覆盖任何已有文件或目录。

## 测试与发布

核心逻辑使用 pytest 做单元与临时目录集成测试，覆盖普通替换、正则捕获组、扩展名保护、层级限制、中文路径、冲突、非法名称、深层优先执行和进度回调。GUI 做入口导入与手工冒烟检查。最终运行完整测试并通过 PyInstaller 构建 EXE，再启动检查产物。
