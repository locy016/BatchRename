# 左下角工具入口与可拖拽浮动面板设计

## 目标

移除左侧流程栏底部没有实际信息价值的“工具”标题，让正则模板和设置入口获得更直接、清楚的层级。两个入口打开的工作面板不再垂直居中后脱离触发位置，而是从对应按钮附近出现，并允许使用者通过标题区域在主窗口内拖拽。

## 交互设计

- 标准与舒展布局只保留“正则模板”和“设置”两个底部入口；紧凑导航继续保留对应图标入口。
- 首次打开面板时，以实际触发按钮为锚点：面板位于按钮右侧，并优先让面板底边接近按钮底边；若空间不足，则自动调整到主内容区可见范围内。
- 正则模板与设置继续互斥。再次点击当前入口、点击关闭按钮、按 Esc 或点击结果区都会关闭面板。
- 标题与辅助说明所在的顶部区域作为拖拽手柄。按下鼠标后记录指针与面板偏移，移动时更新位置，松开后结束拖拽。
- 拖拽位置始终限制在主窗口内容区，面板标题、关闭入口和主要内容不会被拖到窗口之外。
- 面板关闭后清除本次拖拽位置；再次打开时重新贴近本次使用的触发入口，避免窗口缩放或布局切换后沿用失效坐标。

## 视觉设计

- 面板使用独立外壳形成清晰边框，内容继续复用现有正则模板与设置控件，不改变业务状态。
- 外壳后方增加轻微右下偏移的阴影层，建立浮动层级；浅色和深色主题分别使用适合当前背景的边框与阴影颜色。
- 阴影只用于表达层级，不遮挡触发按钮，不参与点击和拖拽。
- 标题区域使用可拖拽光标，并保留明确的关闭按钮；鼠标拖动不影响内部输入、列表选择和一键应用操作。

## 结构与状态

- 为两个现有内容面板增加统一的浮动外壳和阴影容器，不创建独立任务栏窗口，也不改变多显示器焦点策略。
- 记录当前触发控件、当前面板坐标和拖拽起点。窗口缩放、布局档位变化或主题切换时重新约束当前坐标，并同步外壳、边框和阴影颜色。
- 面板尺寸仍根据正则模板和设置的内容规模分别计算；定位逻辑与尺寸逻辑分离，便于使用纯函数覆盖边界场景。

## 异常与边界处理

- 触发控件尚未完成布局、已隐藏或尺寸不可用时，回退到对应导航栏右侧的安全位置。
- 主内容区小于目标面板尺寸时，优先保证边距和标题可见，并沿用现有面板尺寸收缩规则。
- 拖拽过程中窗口尺寸变化时，下一次移动或响应式重排会把面板重新限制在有效区域。
- 忙碌状态继续禁止打开新面板，但允许关闭已经打开的面板。

## 验证范围

- 左下角不再显示“工具”文字，两个入口顺序、宽度与间距保持清楚。
- 标准、舒展和紧凑布局中，正则模板与设置分别贴近实际触发入口。
- 标题拖拽会移动外壳和阴影，且无法越过主内容区四边。
- 内部列表、输入框、选择项、关闭按钮与一键应用不被拖拽绑定干扰。
- 浅色、深色切换后边框与阴影使用当前主题颜色，面板内容和位置不丢失。
- 完整自动化测试、字节码编译和界面冒烟运行继续通过。
