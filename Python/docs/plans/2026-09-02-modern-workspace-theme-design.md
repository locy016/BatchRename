# 现代工作台、目录概况与主题切换设计

## 目标

把当前以深色品牌横幅、紧凑侧栏按钮和底部小浮窗组成的界面，调整为更接近现代生产力应用的扁平工作台。有效信息优先占据固定空间：顶部显示当前目录和扫描范围概况，列表下方显示匹配结果统计，左侧清楚呈现完整重命名流程，正则模板和设置获得符合内容规模的工作面板。

本轮同时提供“跟随系统、浅色、深色”三种外观模式。主题切换只改变视觉，不清空输入、匹配快照、结果预览或执行状态。

## 信息架构

移除主菜单与功能区域之间的深色品牌标题栏。应用名称继续保留在系统窗口标题、“关于”窗口、README和程序图标中，不再占用主工作区高度。

主窗口从上到下分为：

1. Windows系统菜单；
2. 左侧重命名流程与右侧结果工作区；
3. 全局状态栏。

右侧结果工作区内部从上到下分为：

1. 目录概况栏；
2. 匹配结果标题、预览上限和结果表；
3. 匹配统计栏；
4. 执行进度栏。

这一区分把“扫描对象本身的信息”和“当前规则产生的结果”分开。目录概况属于扫描上下文，不随替换内容变化；匹配统计属于当前搜索或预览结果，紧跟结果表呈现。

## 目录概况

目录概况栏显示：

- 当前根目录，长路径使用单行省略并提供完整悬浮文字；
- 当前范围，例如“全部层级”或“最多 3 层”；
- 已遍历文件夹数量；
- 已遍历文件数量；
- 无法读取的位置数量，仅在大于零时用警示色显示。

文件夹和文件数量按当前层级实际遍历到的全部项目统计，不包含根目录本身，也不受“处理文件夹”“处理文件”过滤影响。过滤选项只决定哪些名称可以进入匹配结果。这样目录概况始终回答“当前范围内有什么”，匹配统计回答“当前规则找到了什么”。

扫描前显示当前选择目录和“尚未扫描”；扫描期间显示“正在统计”；扫描完成后使用匹配快照保存的数量。改变根目录、层级或查找条件会使匹配快照失效，其中根目录和层级改变时数量回到“尚未扫描”；只修改替换内容时继续保留目录概况。

匹配快照增加扫描文件夹数和文件数，只在现有目录遍历中累加，不进行第二次磁盘读取。无法访问的项目继续写入错误列表，其数量用于概况提示。

## 匹配统计

原顶部统计文字移动到结果表下方，拆为四个横向状态项：匹配、可修改、名称未变化、阻止执行。每项由简短标题和突出数字组成，在空间不足时保持同一信息顺序并压缩间距，不隐藏任何状态。

扫描匹配完成但尚未生成结果预览时，匹配显示准确数量，其余三项显示“—”。结果预览完成后显示四项准确数字。统计栏不承担操作按钮职责，避免与左侧流程重复。

## 左侧流程

标准布局侧栏从270像素调整到约288像素，舒展布局约304像素，紧凑导航仍保持窄图标栏；紧凑模式展开的工作流抽屉约320像素。最终宽度需要在1120×720最小工作台和高DPI测试中验证，不能造成右侧结果列消失。

左侧内容分成“目录”“规则”“执行”“工具”四个视觉分组，但仍保持现有真实顺序：

1. 选择目录；
2. 普通文本或正则表达式；
3. 查找内容与扫描；
4. 替换内容与结果预览；
5. 确认执行；
6. 正则模板与设置。

输入框和按钮使用统一高度、左右内边距与6至10像素纵向节奏。选择目录和扫描是中性次要操作，结果预览使用强调色，确认执行在可用时使用更明确的最终操作样式，禁用时仍保持可读。规则反馈使用独立浅色提示区域，不和按钮紧贴。

左下角不再把两个工具按钮挤在同一行。“工具”标题下使用两个完整宽度按钮上下排列，图标、文字和展开含义保持一致。紧凑导航继续用图标入口，并通过悬浮说明解释用途。

## 工具工作面板

正则模板和设置仍为窗口内非模态面板，保持与当前规则的上下文联系，不创建额外任务栏窗口。面板从贴底小卡片调整为靠近左侧、垂直居中的浮动工作面板，并增加标题、辅助说明和明确关闭按钮。

标准窗口下目标宽度约620像素，舒展窗口最多720像素；高度根据内容使用，但至少约420像素，并限制在主内容区域内。可用空间不足时优先保持外边距和关闭入口，内部列表或说明区域滚动，不压扁输入控件。

正则模板面板使用约40%/60%的双栏：左侧放分类和模板列表，右侧放用途、查找表达式、替换内容、前后示例、选项提示和一键应用按钮。列表获得主要伸缩高度，一键应用固定在右下方。

设置面板按“扫描范围”“处理对象”“名称保护”分组，选项使用完整文字和补充说明。设置内容规模较小，但面板不再收缩到只包裹控件，而使用稳定宽度和舒适内边距。

## 主题系统

顶部菜单增加“视图”，其中“外观”子菜单提供：

- 跟随系统；
- 浅色；
- 深色。

只保留这一处全局主题入口，避免与左下角设置重复。选项使用单选状态显示当前模式。

视觉基调采用中性表面与靛蓝强调色：

- 浅色：浅灰工作区、白色表面、深灰正文、低对比边界、靛蓝强调；
- 深色：深灰工作区、略亮表面、近白正文、柔和边界、亮靛蓝强调；
- 绿色、橙色和红色继续只表示可修改、未变化和阻止执行等语义状态。

取消大面积深蓝标题背景和传统凸起边框。卡片只在需要形成信息分组时使用轻微表面差异，按钮通过填充、文字、边界和交互状态建立层级。所有前景色与背景色成对配置，Treeview、Canvas图标覆盖层、Tooltip、浮动面板、菜单、进度条、输入框和只读状态都必须随主题更新。

用户选择写入`%LOCALAPPDATA%\BatchRename\settings.json`。只保存请求模式`system`、`light`或`dark`，不保存解析后的颜色。配置缺失、损坏或值未知时回退`system`且不阻止启动。Windows跟随系统模式读取当前应用浅色设置；接口不可用时回退浅色。应用启动、切换为跟随系统以及窗口重新获得焦点时重新解析系统外观。

主题切换原地更新ttk样式、Tk控件颜色和现有覆盖组件，不重建主界面，不重新扫描，不改变任何业务变量。已经打开的工具面板与详情窗口在安全可行的范围内同步主题；无法实时重绘的临时悬浮提示先关闭，下次显示时使用新主题。

## 响应式与空间边界

1120×720继续作为完整工作台下限。去除品牌标题栏释放的高度主要分配给结果表和左侧工具按钮间距，不用来增加空白。标准与舒展模式展示完整侧栏；竖屏或高窄窗口使用紧凑导航和工作流抽屉。

目录概况和匹配统计均为单行优先布局。宽度不足时，根目录文字先省略，统计项缩小间距；文件夹、文件和阻止执行等关键数字不隐藏。工具面板每次打开或窗口缩放后重新计算尺寸和位置，并始终限制在主内容区域内。

## 错误与状态处理

- 配置文件读取或写入失败不会阻止扫描和重命名；状态栏给出一次非阻断提示。
- 目录扫描部分失败时，概况显示成功统计和无法读取数量，现有警告窗口继续列举前几项错误。
- 扫描条件改变后，目录概况和匹配统计按各自的数据依赖清空，不显示过期数字。
- 主题切换不得在后台任务进行时改变控件可用状态；禁用控件在新主题下仍保持禁用。
- 浮动面板切换主题、缩放或关闭时不得残留旧颜色Canvas、Tooltip或位置。

## 验证

自动化测试覆盖：

- 扫描深度内全部文件夹和文件计数，过滤选项不影响概况总数；
- 扫描前、扫描中、扫描后及条件失效时的目录概况；
- 匹配统计位于结果表下方且四项数据口径保持不变；
- 左侧按钮顺序、统一高度、完整宽度工具按钮和最小间距；
- 正则模板与设置面板的最小尺寸、双栏比例、关闭入口和窗口边界；
- 浅色、深色、跟随系统解析、损坏配置回退与选择持久化；
- 切换主题后业务变量、匹配快照、预览和控件状态不变；
- Treeview、Canvas覆盖图标、Tooltip和浮动面板使用当前主题颜色；
- 1120×720、标准、舒展、竖屏及高DPI空间边界；
- 现有扫描、预览、执行、相对目录、语义图标和详情行为继续通过。
