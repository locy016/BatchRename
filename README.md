# 批量重命名工具

一个面向 Windows 的中文图形界面批量重命名工具。它可以扫描所选目录内部 1–N 层或全部层级的文件夹与文件，按普通文本或正则表达式生成预览，并在二次确认后显示逐项处理进度。

## 主要功能

- 根目录自身不改名，只处理其内部项目。
- 默认扫描到最深层，也可限制为 1–N 层。
- 文件夹与文件分别统计、分别显示前若干条预览。
- 支持普通文本替换和 Python 正则表达式捕获组。
- 默认保护文件扩展名，可显式允许修改。
- 目标已存在、批内目标重复或 Windows 名称不合法时安全跳过。
- 执行前二次确认；执行中显示当前项目与总体进度。
- 控件可见说明、悬停提示、状态栏反馈和完整“使用说明”。
- PyInstaller 单文件、无控制台窗口发布。

## 使用方法

1. 运行程序，选择要处理的根目录。
2. 使用默认“全部层级”，或选择“限制为”并输入 1–N。第 1 层是根目录中的直接子项。
3. 输入“查找内容”和“替换为”，选择普通文本或正则表达式模式。
4. 选择处理文件夹、文件或两者。除非确实需要，否则不要开启“允许修改文件扩展名”。
5. 点击“扫描预览”。此步骤只读取名称，不会修改磁盘。
6. 检查两个分类标签页中的原名称、新名称、状态和说明。
7. 点击“执行重命名”，再次核对汇总，并在确认后等待进度完成。

## 规则示例

普通文本：

- 查找：`旧版`
- 替换为：`新版`
- `旧版-资料-旧版.docx` 会变为 `新版-资料-新版.docx`。

正则日期：

- 查找：`(\d{4})-(\d{2})-(\d{2})`
- 替换为：`\1\2\3`
- `照片-2026-08-27.jpg` 会变为 `照片-20260827.jpg`。

删除文本：将“替换为”留空即可删除匹配内容。若结果为空或产生非法名称，该项目会在预览中标出并跳过。

## 安全说明

- 本工具绝不覆盖同目录中已有的文件或文件夹。
- 多个来源生成同一个目标名称时，相关项目全部跳过。
- `CON`、`PRN`、`AUX`、`NUL`、`COM1`–`COM9`、`LPT1`–`LPT9` 等 Windows 保留名称会被拒绝。
- 名称中的 `< > : " / \ | ? *`、控制字符、末尾空格和末尾句点会被拒绝。
- 符号链接不跟随，避免扫描越出所选目录。
- 执行时再次检查来源和目标，以处理扫描后发生的文件系统变化。
- 先处理更深层项目，再修改父文件夹名称。
- 工具不提供自动撤销。重要目录应先备份，并认真检查预览。

## 从源码运行

需要 Python 3.11 或更高版本。运行时仅使用 Python 标准库。

```powershell
python main.py
```

## 测试

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

## 构建单文件 EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

构建完成后产物位于：

```text
dist\BatchRename.exe
```

`build.ps1` 会先运行全部测试，只有测试通过后才调用 PyInstaller。生成的 EXE 不依赖目标计算机预先安装 Python。
