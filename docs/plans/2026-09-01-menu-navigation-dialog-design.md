# 菜单导航、两阶段预览与弹窗管理设计

## 目标

本轮将“批量重命名”从控件集中排列的工具界面调整为更接近正式发行软件的工作台。主窗口使用顶部全局菜单、左侧完整操作流程和右侧结果工作区；主内容不再散布操作按钮。扫描与结果预览拆成两个真实阶段，为下一轮操作日志和撤回功能建立稳定的数据边界。

版本从 `1.0.0` 调整为 `1.1.0-beta.1`。该版本处于快速开发期，但界面、文案、状态管理与弹窗行为均按正式发行要求设计。日志与撤回本轮只在菜单中明确占位，不提供伪功能。

## 方案选择

评估过三种实现方向。

第一种只移动控件，扫描仍要求替换内容。它改动较小，但左侧显示“先扫描、后替换”时，内部状态仍与界面顺序矛盾。

第二种在扫描阶段只展示名称，点击结果预览后重新遍历目录。它能够形成两步界面，但大目录需要重复读取，扫描结果也无法成为后续日志和撤回的可靠快照。

最终采用真正的两阶段核心。扫描阶段按目录、层级、对象范围、普通文本或正则规则生成匹配快照；结果预览阶段只使用该快照和当前替换选项计算目标名称、安全状态与冲突。执行阶段仍只接收已经生成并确认的安全候选项。

## 主窗口结构

默认与最小尺寸继续保持 960×680，并支持最大化自适应。窗口由顶部系统菜单、左侧流程栏和右侧结果工作区组成。

左侧栏固定为约 270 像素。右侧工作区获得剩余宽度和全部可扩展高度。移除原扫描范围卡片、规则卡片中的操作按钮、顶部使用说明按钮以及横向操作按钮行后，结果列表在默认尺寸下仍保有充足空间。

### 左侧操作流程

左侧按真实操作顺序纵向排列：

1. 选择目录。
2. 选择查找模式：普通文本或正则规则。
3. 输入查找内容。
4. 扫描匹配。
5. 输入替换内容。
6. 生成结果预览。
7. 确认执行。

目录路径、查找模式、查找内容和替换内容属于流程字段；选择目录、扫描匹配、结果预览和确认执行属于流程命令。所有原主界面按钮均迁移到左侧流程栏或顶部菜单，不在结果工作区重复。

扫描前，结果预览不可用；扫描完成后才启用。存在至少一个可安全修改项时，确认执行才可用。结果详情不再使用主窗口按钮，执行完成后从状态提示或顶部查看入口打开。

### 左下角浮动入口

左侧底部放置两个紧凑图标：正则模板和设置。图标带文字提示与悬停说明，避免只依赖难以理解的符号。

两个浮动面板互斥：同一时间只能展开一个；再次点击当前图标、点击主内容区或按 `Esc` 时收起。面板贴近左侧栏向右展开，不改变主窗口网格宽度，也不跨越主窗口所在显示器。

正则模板面板沿用现有六类十五条模板、用途说明、处理前后示例和一键应用能力。应用后关闭面板，填写查找规则并使既有扫描快照失效。

设置面板包含扫描层级、处理文件夹、处理文件、扩展名保护和预览上限。层级和对象范围影响扫描快照；扩展名保护影响结果预览；预览上限只影响界面显示条数。

## 顶部菜单

顶部菜单只承担全局功能，不重复左侧操作流程：

- 文件
  - 退出
- 功能
  - 撤回管理（开发中）
  - 操作日志（开发中）
- 帮助
  - 使用说明
  - 关于

日志和撤回使用禁用菜单项并带“开发中”文字。它们是下一轮开发的产品路线图入口，不弹出空白功能、不写入数据，也不向用户暗示当前可用。

## 两阶段数据与状态流

扫描阶段使用独立的搜索选项，不包含替换内容。结果包含根目录、匹配来源、对象类型和扫描提示。匹配项目保持文件夹优先、文件其次和同类自然名称排序。

预览阶段根据匹配快照、替换内容、正则捕获组和扩展名保护生成现有的重命名候选结构，继续执行目标冲突、批内重复、Windows 非法名称与名称未变化检查。执行器及深层项目优先策略保持不变。

主窗口保存两个独立状态：最近扫描快照和最近结果预览。目录、层级、文件／文件夹范围、查找模式或查找内容变化时，两者同时失效。替换内容或扩展名保护变化时只清除结果预览，保留扫描快照。预览上限变化只重绘表格。

扫描完成但尚未生成结果预览时，表格展示类型、所在目录和原名称，新名称留空，状态为“等待结果预览”，说明提示填写替换内容后继续。生成预览后恢复新名称强调色、安全状态和说明。

## 弹窗管理

使用说明、关于、正则模板和结果详情统一由弹窗管理器登记。每种弹窗只保留一个实例；重复打开时还原最小化窗口、置前并重新获得焦点。

新窗口先计算请求尺寸，再以主窗口中心为基准定位。位置限制在主窗口当前所在显示器的工作区域内，避免多屏环境下分散到另一块显示器。需要用户完成选择的正则模板使用模态焦点；说明、关于和结果详情保持非模态，但始终设置 `transient`、短暂置前并主动聚焦。关闭弹窗后焦点返回主窗口或先前控件。

系统消息框继续显式指定主窗口为父级，使确认、警告和错误跟随当前应用窗口。

## 关于窗口

关于窗口使用产品化信息分区，不采用一整块机械说明文字。内容包括：

- 产品名称与版本 `1.1.0-beta.1`。
- 当前能力：多层扫描、文件夹与文件、普通文本和正则、模板库、两阶段预览、安全冲突检查、确认执行、处理进度与结果详情。
- 正在开发：撤回管理和操作日志，并说明将在紧随本版本的开发任务中实现。
- 快速开发期说明：界面和功能仍会持续演进。
- 数据安全与免责声明：批量改名不可由当前版本自动撤回，重要目录应先备份；用户应在执行前核对预览，对自行确认的磁盘操作负责。
- 联系作者：`lo.c@live.cn`。

联系地址以可选择文本显示，不自动打开邮件客户端，不触发外部传输。

## 视觉语言

继续使用现有深蓝、青绿色、浅灰和白色体系。左侧栏使用深蓝背景、分组标题、步骤编号和清晰的活动／禁用状态；危险性较高的确认执行使用明确但不过度警示的强调色。顶部菜单保留操作系统原生行为，以获得标准键盘导航与多语言字体兼容。

浮动面板使用白色卡片、边框、柔和阴影感和明确标题。图标、菜单、字段和结果表遵循同一字体层级。默认尺寸下不出现不必要的横向滚动，最大化后新增空间优先进入结果列表。

## 快捷键与可访问性

左侧流程支持标准键盘操作：目录、模式、查找内容、扫描、替换内容、结果预览与确认执行可通过 `Tab` 顺序访问。查找框按 Enter 触发扫描；替换框按 Enter 触发结果预览。`Esc` 优先关闭浮动面板。

顶部系统菜单支持 Alt 键导航。帮助菜单提供 F1 使用说明。所有图标同时提供可读文字或悬停说明，不能只以颜色表达状态。

## 测试与发布验证

自动化测试覆盖：

- 扫描阶段不要求替换内容。
- 预览阶段不重复读取目录。
- 搜索设置与替换设置分别使正确状态失效。
- 未扫描、已扫描、已预览和已执行四种界面状态。
- 顶部菜单与左侧流程不存在完全重复的布局入口。
- 日志和撤回显示“开发中”并保持禁用。
- 浮动面板互斥、再次点击与 Esc 收起。
- 弹窗单实例、父子关系、定位范围与焦点恢复。
- 关于窗口版本、功能、路线图、免责声明和联系信息完整。
- 960×680 请求尺寸、结果区域伸缩和既有安全执行测试。

完成后在 Windows 多显示器环境实际启动，检查主窗口所在屏幕上的使用说明、关于、正则模板与结果详情定位；按完整左侧流程完成真实目录扫描、预览和确认前检查。随后运行全部测试、字节码检查和 PyInstaller 单文件构建，记录产物大小与 SHA-256。
